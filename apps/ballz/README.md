# Ballz — Idle Ball Factory

A Cookie-Clicker-style idle game. Click balls, buy generators, trigger golden
ball events (Frenzy, Lucky, Click Frenzy, Ball Storm, Builder's Boon, Jackpot),
buy 80 generator tier upgrades, prestige into a 7-tier skill tree, fight
Leechers, and break reality with the Overflow.

**Live:** [ballz.lobslab.com](https://ballz.lobslab.com)

Single-file static app (`index.html`) served via nginx.

## Dev

```sh
bin/dev-run      # serve on http://localhost:47100
bin/dev-status
bin/dev-stop
npm test         # jest suite (extracts game JS from index.html)
```
